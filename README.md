# Router-Wartung-mikrotik-hap-
MikroTik hAP ax2: RouterOS-Update und Grundkonfiguration.# MikroTik hAP ax2 – mein Lab-Router

Ich habe den MikroTik hAP ax2 als zweiten Router für mein Homelab bekommen und ihn zuerst auf den neuesten Stand gebracht, bevor ich ihn für Tests nutze.

## Warum
Ein Router ist der Eingang ins Netzwerk. Mit alter Firmware können Sicherheitslücken offen bleiben, deshalb wollte ich nicht einfach mit dem Auslieferungszustand starten. Außerdem soll mein Lab-Netz getrennt vom normalen Heimnetz laufen, damit meine Tests nichts durcheinanderbringen.

## Was ich gemacht habe
1. Über WinBox am Router eingeloggt
2. Unter **System → Packages** nach Updates gesucht und RouterOS aktualisiert, danach Neustart
3. Unter **System → RouterBOARD** die Firmware aktualisiert und nochmal neu gestartet
4. Grundeinstellungen geprüft: [z. B. Admin-Passwort geändert, nicht gebrauchte Dienste ausgeschaltet]
